Service settings

Restart required after saving

Configuration

Keep the complete JSON structure. Listener, database, and WebUI changes require a restart. Disabling the WebUI will make this console unavailable.

The listener is overridden by a startup argument. Editing the configuration will not override that argument.

Official usage sync is controlled by usage.enabled, usage.refresh_interval (default 5m), and usage.max_attempts (1–5, default 3). Disabling it stops automatic sync, not manual sync. Save and restart to apply.
